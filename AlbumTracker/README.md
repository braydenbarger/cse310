# Spinlog

Spinlog is a music logging site. Users can search for an album, rate it, and ask for album recommendations.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Download or clone the project.
2. Open the project in a code editor.
3. Run the site using a local server.

Instructions for using the software:

1. Search for an album.
2. Select the album and give it a rating.
3. Ask for album recommendations.

## Development Environment

To recreate the development environment, you need:

- TypeScript
- Visual Studio Code
- Web browser
